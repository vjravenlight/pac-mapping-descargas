# PAC-MAPPING · descargas

Acá están los archivos de cada versión de **PAC-MAPPING**: el arcade de 1980 jugado sobre cualquier cosa que proyectes. Gratis. Por VJ Ravenlight.

- **Qué hace y cómo se usa:** https://pacmapping.ravenlight.net
- **Para bajarla:** entrá en [Releases](https://github.com/vjravenlight/pac-mapping-descargas/releases/latest), bajá el `.zip`, descomprimilo y abrí `PAC-MAPPING.exe`. Es para Windows 10 y 11 de 64 bits y no se instala.
- **La primera vez te pide tu `pacman.zip`**, el set `pacman` o `puckman` de MAME. La app no trae nada de Namco: los gráficos, los colores, las velocidades y el sonido salen de tu ROM.

Este repositorio solo guarda las versiones listas para usar.
